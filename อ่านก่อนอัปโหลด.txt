โลกของคุณไข่ เวอร์ชัน 2

1. แตกไฟล์ ZIP ก่อน
2. เปิด GitHub repository khunkhai-world -> Add file -> Upload files
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ (รวมโฟลเดอร์ icons) ขึ้น GitHub ที่ root โดยไม่สร้างโฟลเดอร์ครอบ
4. ระบบจะตรวจไฟล์ชื่อซ้ำ ให้เลือกแทนที่ (ถ้าหน้า GitHub ไม่ให้ทับไฟล์ ให้แก้แต่ละไฟล์ผ่าน Edit หรือใช้ GitHub Desktop)
5. กด Commit changes แล้วเปิดเว็บใหม่ หากยังเป็นของเดิมให้รีเฟรชแบบข้ามแคช Ctrl+Shift+R หรือ Cmd+Shift+R

ปรับแล้ว: โทนท้องฟ้าสีชมพูม่วงฟ้าส้ม + ปุ่มซ่อนเมนูด้านขวาแบบเลื่อนและเรียกกลับ + เก็บสถานะเมนู
หมายเหตุ: โค้ดเป็นฉากวาดด้วย CSS ไม่ใช่ภาพมอกอัพที่สร้างจาก AI แบบตรงทุกพิกเซล
