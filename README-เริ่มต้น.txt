รู้ใจแค่ไหน? — Love Match 💗

เกมคู่รักสำหรับเล่นบนมือถือเครื่องเดียว สลับกันตอบคำถามลับและทายใจ
- เลือกชื่อผู้เล่นและจำนวน 2–20 รอบ
- คำถามตัวอย่าง 10 ข้อ พร้อมตัวเลือก 4 ข้อต่อคำถาม
- คนแรกล็อกคำตอบลับแล้วเลือกบทลงโทษสำหรับคนทายผิด
- ส่งมือถือให้อีกคนเดา / เฉลยคำตอบ / ให้ 10 คะแนนเมื่อทายถูก
- แสดงการ์ดบทลงโทษเมื่อทายผิด และมีปุ่มข้าม
- หน้าตั้งค่าเพิ่ม แก้ไข และลบคำถามและบทลงโทษได้เอง
- ข้อมูลส่วนตัวเก็บบนอุปกรณ์ด้วย localStorage ไม่ได้ซิงก์ระหว่างเครื่อง
- เล่นแบบออฟไลน์ได้หลังเปิดเว็บครั้งแรก (Google Fonts อาจใช้ fallback)

วิธีเผยแพร่ด้วย GitHub Pages:
1. สร้าง Repository ใหม่ เช่น love-match (อย่าอัปโหลดทับโปรเจกต์เก่า)
2. อัปโหลดไฟล์ทั้งหมดจากโฟลเดอร์นี้ไปที่ root ของ Repository (อย่าอัปโหลดเป็น ZIP)
3. Commit changes
4. Settings > Pages > Deploy from a branch > main > /(root) > Save
5. เมื่อเผยแพร่เสร็จ เปิด URL ที่ GitHub Pages แสดง

การติดตั้งมือถือ:
- iPhone Safari: Share > Add to Home Screen
- Android Chrome: เมนู > Install app / Add to Home screen
- Mac/PC บนเบราว์เซอร์ที่รองรับ: Install app ในแถบที่อยู่หรือเมนู

หมายเหตุ:
เกมเวอร์ชันแรกไม่ใช่มัลติเพลเยอร์ออนไลน์ และไม่ได้ส่งข้อมูลข้ามอุปกรณ์
บทลงโทษเป็นกิจกรรมขำ ๆ หรือเครื่องดื่มไม่มีแอลกอฮอล์ ผู้เล่นข้ามได้เสมอ
