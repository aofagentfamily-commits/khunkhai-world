Love Match Pastel V4 — ตามภาพมอกอัพที่เลือก

- หน้าหลัก: ปุ่มเล่นเกมทายใจ / เปิดกล่องเกมสนุก / เพิ่มคำถาม / แก้บทลงโทษ พร้อมงานภาพอ้างอิงจากมอกอัพล่าสุด
- หน้าเกมทายใจ: ภาพตัวละครสองฝั่ง, คำถามกลาง, ช้อยส์ภาพประกอบแทนอิโมจิ, ปุ่มล็อกคำตอบ
- ระบบเล่นเดิม: ทายใจ, เฉลย, คะแนน, เพิ่มแก้ไขลบคำถามหรือบทลงโทษ, เกมสนุก 10 เกม
- ไฟล์ assets ใช้เป็นภาพประกอบ UI และต้องอัปโหลดทั้งโฟลเดอร์
- ยังคงเป็นเว็บ PWA เล่นสองคนบนเครื่องเดียวและใช้ localStorage เก็บข้อมูล

นำขึ้น GitHub:
1) แตก ZIP
2) อัปโหลดไฟล์และโฟลเดอร์ assets ขึ้น root ของ repository เดิม (แทนไฟล์ชื่อซ้ำ)
3) Commit changes แล้วตรวจ GitHub Pages deployment
4) หากยังเป็นหน้าเดิม ทดลองเปิดใน Incognito (service worker อาจเก็บ cache เก่า)

หมายเหตุ: ส่วนภาพประกอบบางส่วนเป็นภาพ WebP จากมอกอัพเพื่อให้ตรงกับภาพอ้างอิง ส่วนข้อความ/คำถามและปุ่มเป็น HTML ที่ตอบสนองต่อการกดได้จริง การจัดวางปรับตามขนาดหน้าจอ จึงไม่สามารถตรงทุกพิกเซลในทุกขนาดจอ
